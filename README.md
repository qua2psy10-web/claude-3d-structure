# 構造物3Dモデラー

擁壁・ボックスカルバート・桁橋などの土木構造物を、通常の2次元図面から3Dモデルにするブラウザアプリです。
インストール不要で、`index.html` をブラウザで開けば動きます（iPhone / iPad / Mac 対応）。

## できること

- **寸法入力**: 構造物の種類を選び、図面の寸法（mm）を入れるとその場で3Dになる
  - 逆T型擁壁 / L型擁壁 / 重力式擁壁 / ボックスカルバート / U型水路 / 桁橋（橋台・橋脚つき）
- **AI読み取り**: 図面（PDF・画像）の表示中の範囲をAIが読み、寸法を拾って3Dモデルを組み立てる。読み取った値と根拠、読み取れなかった項目を一覧で表示
  - claude.ai で公開したページ上でのみ動作（閲覧者自身のClaude利用枠を使用。APIキー不要）
- **図面トレース**: 図面（PDF・PNG・JPEG）を読み込み、寸法線で縮尺を合わせ、断面の輪郭をなぞって奥行きを与える
  - 中抜き（空洞）にも対応
- **円柱・変断面**: 円柱（テーパーつきも可）、鉛直方向の押し出し、始端と終端で輪郭が異なる変断面の部材に対応
  - 擁壁は起点側と終点側で高さを変えられる。桁橋は中間支点上で桁高を増す変断面桁と、円柱橋脚を選べる
- **曲線・斜角**: 平面曲線半径を入れると断面が円弧に沿って並び、斜角を入れると端面が斜めに切れる
  - 桁橋は上部工が曲線に沿い、橋台・橋脚は支承線に平行に配置される。擁壁・水路は曲線、ボックスカルバートは曲線と斜角に対応
- **緩和曲線・縦断勾配・片勾配**: 円弧の前後にクロソイド（緩和曲線長で指定）、始端と終端の縦断勾配（異なれば縦断曲線）、片勾配（始端と終端で変えればすり付け）を指定できる
- **S字・複数の曲線**: 線形を区間ごとに「長さ, 半径」「長さ, 勾配」「長さ, 片勾配」の表で指定できる。直線・円弧・クロソイドの連続、勾配変化点が複数ある縦断、区間ごとの片勾配に対応
  - 桁橋の片勾配は、区間指定がなければ曲率に比例して自動で付き、緩和曲線の中ですり付く
- **沓座・支承**: 桁橋は支点ごと・主桁ごとに沓座（台座）と支承を置く。台座の天端は水平で、片勾配による桁ごとの高さの違いが段差になる
- **アンカーボルト・落橋防止**: 支承ごとに4本のアンカーボルト、主桁のあいだに変位制限ブロック、橋台に落橋防止ケーブルと定着板を置く。同じ形の部材は支点ごとに1つにまとめて一覧に出す
- **単純桁と桁連結**: 桁橋の主桁を径間ごとに分けた単純桁にできる。橋脚上は支承が2列になり、隣り合う径間の桁を連結ケーブルでつなぐ
- **部材の編集**: 名称・色・奥行き・位置・回転・輪郭座標を数値で修正、複製
- **数量**: 部材ごとと全体のコンクリート体積（m³）、外形寸法を表示
- **保存**: 作業データ（.json）、3Dモデル（OBJ / STL、単位 m、Y軸が上）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `src/app.html` | アプリ本体（HTML・CSS・JavaScript を1ファイルに収めたもの） |
| `index.html` | `src/app.html` から生成した、そのまま開けるページ |
| `build.mjs` | `node build.mjs` で `index.html` を作り直す |

3D表示には three.js、PDFの読み込みには PDF.js を CDN から読み込みます（初回はネット接続が必要）。

## 制限

- AI読み取りは寸法の読み違いを含むことがあります。結果は必ず図面と照合してください。`index.html` を直接開いた場合は使えません。
- 形状は「断面 × 奥行き」の押し出しと、始端・終端の輪郭を直線でつなぐ変断面の組み合わせです。配筋は扱えません。
- 平面線形と縦断は数値積分で求めています。座標は設計計算書の値とわずかに異なることがあります。
- 支承・アンカーボルト・落橋防止ケーブルは位置と大きさを示す概略形状です。支承の種別、下沓・上沓、ブラケット、緩衝材、桁かかり長の照査は扱いません。これらの鋼部材はコンクリート体積に含めません。
- 変断面は始端と終端の輪郭の点数が同じである必要があります。途中で折れる変化は部材を分けて表します。
- 体積は断面積 × 奥行きを3D形状から直接求めた概算です。数量計算書の代わりにはなりません。
